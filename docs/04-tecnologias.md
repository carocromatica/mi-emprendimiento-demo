# Tecnologías del proyecto — Brote

> Guía: [Tecnologías del proyecto](../evaluacion/guias/fase-1-requerimientos/04-tecnologias.md)

## Stack

| Área | Herramienta | Para qué la uso |
|---|---|---|
| Construcción | HTML + CSS | Maquetar las páginas del sitio sin depender de un gestor de contenido |
| Versionado | Git y GitHub | Guardar el avance con commits y tener el proyecto en la nube |
| Publicación | GitHub Pages | Publicar el sitio gratis con una URL pública |
| Diseño | Whimsical | Armar el moodboard, calcar componentes y hacer wireframes |
| Diseño | Google Stitch | Generar el prototipo en alta fidelidad a partir de mis specs |
| IA | Claude | Ordenar ideas y revisar mis documentos |
| Editor | Claude Code | Escribir los documentos y, en la Fase 3, el código |

## Qué es funcional y qué es prototipo

## Integraciones para una versión real

- **Pasarela de pago:** Webpay o Mercado Pago.
- **Despacho:** integración con una empresa de courier para calcular costos por comuna.
- **Email marketing:** herramienta para guardar los correos, enviar la guía de cuidados y, más adelante, los recordatorios.
- **Comentarios:** un servicio externo de comentarios para el blog.

## Restricciones

- **Plazo:** 29 de septiembre al 14 de octubre de 2026.
- **Marca:** no hay manual de marca ni logo; la identidad visual se define en la Fase 2.
- **Dispositivos:** el sitio debe funcionar en celular y escritorio, priorizando celular porque Camila compra desde el teléfono.
- **Contenido:** los productos, precios y artículos son ficticios.
